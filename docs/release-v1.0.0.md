# v1.0.0 · 从全国地图，看学校与电网的双向去向

Hengzhen Grid Atlas 首次公开源码与本地合成演示。它将分散在地区、学校、招聘主体和批次中的信息放进同一套可查询界面，帮助开发者构建可解释、可维护的招聘数据产品。

## 本版亮点

- **一张地图，两种省份排名。** 既能看全国高校进入某省电网的来源，也能看这个省的高校进入全国电网的去向；学校所在地与招聘目的地分别统计。
- **从前 200 到每校明细。** 全国学校榜在固定面板内滚动，完整学校表保留国网三批、南网秋春招、分电网小计和总计。
- **电脑与手机各有阅读方式。** 桌面支持地图与并列面板；手机以搜索、短摘要和逐级详情组织信息。
- **前台、管理端和 API 分开维护。** 提供 Vue / TypeScript 前端、Fastify API、PostgreSQL 数据层与独立管理端源码。
- **可直接体验的合成数据。** 本地演示提供 240 所虚构学校、三个省份与五批数据，不需要线上账号或生产数据库。

## 开始体验

按仓库 README 安装 Node.js 24.x 与三个应用的依赖后运行：

```bash
npm run demo
```

桌面、手机与管理端地址、仅供演示的账号和验证命令见 [README](../README.md)。
