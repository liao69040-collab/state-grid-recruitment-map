# 数据模型与范围

一个可解释的统计值至少需要回答：哪一年、哪个电网、哪个批次、哪个主体、什么范围，以及统计的是什么。

## 核心维度

| 维度 | 含义 | 注意事项 |
|---|---|---|
| 资料届别 | 来源记录描述的招聘届别 | 与用户计划报考的届别分别保存 |
| 电网 | 国网、南网或其他明确主体 | 不能仅由地理位置推定 |
| 招聘批次 | 国网一/二/三批、南网秋/春招等 | 保留各电网原生批次，不能任意对齐 |
| 招聘主体 | 公告或公示中的公司、单位 | 同省多个主体不直接合并为同一公司 |
| 招聘目的地 | 记录对应的工作/录用地区 | 与考试地点、宣讲地点、学校所在地分开 |
| 学校与校区 | 规范名称、别名、独立校区键 | 异地校区按各自身份与所在地统计 |
| 指标 | 报名人数/人次、计划人数、公示记录数等 | 不同指标不得替换 |
| 来源 | 发布主体、原文、日期与适用范围 | 来源更新和数据更正需要可追踪 |

## 两种省份排名的查询约定

目的地榜使用招聘目的省筛选；省内高校全国榜使用 `schoolProvinceAdcode` 选择学校/校区所在地，并保留全国招聘去向。后者不应同时附加目的地限制，否则会误变成“本省高校进入本省电网”。

当前范围内的学校排名、国网/南网小计、分批明细与总计应能相互核对。空值、未知值和明确的零各有意义，不互相替换。

## 条件与分数

条件匹配保留规则的来源年份、招聘单位、批次、专业、学历和适用学校范围。历史资料可用于参考方向，不自动转成下一届资格。缺少必要条件时返回待确认，不能因为未发现限制就宣称符合。

电网笔试线、综合录取线和高考分数是不同记录。高考分数还需招生省份、科类/选科、专业、批次及投档/录取指标。省份级的总体标签不能覆盖某岗位、学校或专业的具体限制。

## 公开包与自有数据

公开包只提供标记为演示的虚构业务数据。真实省份名称和地图用于界面定位，不意味着演示招聘记录真实存在。演示账号、学校、数量与条件不能用于推断真实招生或招聘情况。

接入授权数据时建议执行：

1. 保存来源及许可信息，并明确记录允许公开的字段。
2. 规范学校、校区和招聘主体标识，保留原始名称映射。
3. 核对年份、批次、统计指标、地区归属和去重规则。
4. 用可重复的检查验证各维度小计与总计。
5. 对未知或冲突记录保留审核状态，不推断补全。
6. 在独立环境检查页面展示，再发布对应的数据版本。

请勿向公开仓库提交个人名册、身份证号、联系方式、账号会话、私有原文附件或无权再分发的素材。软件许可不改变数据和素材自身的使用条件。
